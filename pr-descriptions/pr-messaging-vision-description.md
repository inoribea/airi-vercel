# Feature: Messaging and Vision Modules

## Summary
This PR adds comprehensive messaging and vision modules with UI components and stores to enable communication and image processing capabilities in AIRI.

## Details
- Implements messaging modules for various platforms (Discord, Telegram, X/Twitter)
- Adds vision module for image processing and analysis
- Creates UI components for messaging configuration
- Implements image upload and preview functionality
- Provides stores for managing messaging and vision state

## Changes
- Added messaging components in `packages/stage-ui/src/components/modules/`
- Created vision components with image processing capabilities
- Implemented messaging stores for state management
- Added image upload and preview components
- Created vision store for image analysis functionality
